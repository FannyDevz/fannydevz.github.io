# 📄 Resume

A **resume site** generated from [JSON Resume](https://jsonresume.org/schema/) data, with English (`resume_en.json`) and Indonesian (`resume_id.json`) versions.

![Preview](preview.png)

> Part of the **one-day-one-code** repo — see the full catalog in [`../index.html`](../index.html).

## Run

Needs Node.js:

```bash
npm install
npm run dev   # or: npm run build
```

## Tech

Vite + TypeScript, vite-plugin-handlebars, Tailwind CSS, Sass. Project stars are fetched from the GitHub API at build time.
