🦊 How to install in Firefox

  1. Open Firefox and type about:debugging#/runtime/this-firefox in the URL bar.
  2. Click Load Temporary Add-on…
  3. Select the manifest.json file located in this directory.
  4. Navigate to TikTok Studio Content to use it live!

⚠️ Deletion on TikTok Studio is permanent. Always review the scanned list before confirming bulk deletion.
