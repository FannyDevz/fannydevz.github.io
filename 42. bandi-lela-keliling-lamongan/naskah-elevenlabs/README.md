**Arti kode:** huruf depan = tokoh (**B** Bandi, **L** Lela, **K** Kayla, **G** Bu Guru), angka = urutan muncul di video.

**Aturan nama berkas:** `KODE.mp3`, misalnya `B01.mp3`, `L06.mp3`, `K11.mp3`, `G03.mp3`. Jika membuat beberapa versi, beri akhiran: `B01_2.mp3` (versi yang dipakai nanti cukup diganti namanya menjadi `B01.mp3`).

**Simpan semua di:** `animasi/suara/dialog/`

**Catatan teks:** angka sudah ditulis dengan huruf ("empat puluh tujuh", "dua ribu dua puluh lima") supaya dibaca benar oleh AI. Tanda "…" sengaja dibiarkan untuk jeda.

**Tag emosi** seperti `[whispers]` atau `[excited]` hanya untuk model **Eleven v3**. Jika memakai model lain, salin versi tanpa tag.

**`dialog.csv`** berisi semua baris dalam satu tabel, untuk dipakai skrip otomatis (cara API) nanti.
