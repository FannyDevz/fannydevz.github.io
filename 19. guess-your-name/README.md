# 🔮 GuessYourName

A **guessing game** that works out the name of a friend, or any name you have in mind, as long as it has 3 to 7 letters.

![Preview](preview.png)

> Part of the **one-day-one-code** repo — see the full catalog in [`../index.html`](../index.html).

## Run

Needs Node.js:

```bash
npm install
npm start   # http://localhost:3000
```

## Tech

React (Create React App), React Router, React Bootstrap, Animate.css.
