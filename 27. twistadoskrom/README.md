# 🔁 Twistadoskrom

A small **link converter** that cleans up a disguised link and rewrites it into a normal `twitter.com` URL.

![Preview](preview.png)

> Part of the **one-day-one-code** repo — see the full catalog in [`../index.html`](../index.html).

## Run

Needs PHP, because the conversion runs in `convert.php`:

```bash
php -S localhost:8000   # http://localhost:8000
```

## Tech

HTML + CSS + Vanilla JS, with a PHP endpoint.
