# Naskah Voice-over — Misi Terakhir Sang Pahlawan (Video 1)

Untuk **ElevenLabs Eleven v3** (mendukung *audio tag* dalam kurung siku seperti `[serious]`, `[whispers]`).
Satu narator dari awal sampai akhir.

## Pengaturan yang Disarankan

| Pengaturan | Nilai |
| :--- | :--- |
| Model | **Eleven v3** (audio tag hanya berfungsi di v3) |
| Bahasa | Indonesian |
| Karakter suara | Narator pria/wanita, hangat, berat, sinematik (gaya trailer dokumenter) |
| Stability | **Natural** (pilih *Creative* bila ekspresi kurang terasa) |
| Speed | 0.95–1.0 |
| Output | MP3/WAV 44.1 kHz |

**Cara generate:** buat **satu file per scene** (`vo_s1_prolog.mp3` … `vo_s8_penutup.mp3`, lihat daftar nama di bagian Tips) agar mudah diselaraskan dengan animasi. Usahakan durasi tiap file tidak melebihi **Target maks**. Bila terlalu panjang, naikkan Speed sedikit atau kurangi tag `[pause]`.

## Daftar Tag yang Dipakai

| Tag | Fungsi |
| :--- | :--- |
| `[serious]` `[solemn]` | Nada serius, khidmat |
| `[softly]` `[whispers]` | Lembut / berbisik |
| `[sighs]` `[exhales]` | Helaan napas (efek emosional) |
| `[curious]` `[mysterious]` | Nada bertanya, misterius |
| `[proud]` `[warmly]` | Bangga, hangat |
| `[confident]` `[cheerful]` | Yakin, ceria ringan |
| `[cautious]` `[tense]` | Waspada, menegangkan |
| `[determined]` `[inspired]` | Tegas, membakar semangat |
| `[dramatic]` | Penekanan sinematik |
| `[pause]` `[short pause]` `[long pause]` | Jeda |

Elipsis (`...`) juga membuat jeda alami, dan huruf KAPITAL memberi penekanan kata.

## Scene 1 — Prolog: Jejak Perjuangan
**Timecode:** 00:00–00:15 · **VO mulai:** 00:02 · **Target maks:** 12 dtk
**Arah:** Pelan, berat, khidmat. Seperti mengenang.

```
[solemn] [softly] Dulu... kemerdekaan bukanlah sesuatu yang mudah didapatkan. [pause] [serious] Ada darah... air mata... dan pengorbanan, [short pause] [sighs] yang menjadi harga dari kebebasan bangsa ini.
```

## Scene 2 — Pertanyaan: Apakah Perjuangan Telah Selesai?
**Timecode:** 00:15–00:30 · **VO mulai:** 00:16 · **Target maks:** 12 dtk
**Arah:** Mulai lebih terang, lalu turun ke nada misterius saat bertanya.

```
[warmly] Kini, kita hidup di alam kemerdekaan. [pause] [mysterious] Namun... satu pertanyaan masih tersisa. [long pause] [curious] [softly] Apakah perjuangan para pahlawan... benar-benar telah SELESAI?
```

## Scene 3 — Rupiah: Simbol Kedaulatan
**Timecode:** 00:30–00:50 · **VO mulai:** 00:31 · **Target maks:** 17 dtk
**Arah:** Membangun semangat. Tekankan kata "Rupiah" di akhir.

```
[serious] Perjuangan tidak berhenti ketika kemerdekaan diraih. [pause] [confident] Hari ini, kita memiliki tanggung jawab untuk menjaga kedaulatan bangsa. [short pause] Salah satunya melalui sesuatu yang setiap hari kita gunakan: [pause] [proud] [dramatic] RUPIAH.
```

## Scene 4 — Cinta, Bangga, Paham Rupiah
**Timecode:** 00:50–01:15 · **VO mulai:** 00:51 · **Target maks:** 22 dtk
**Arah:** Hangat dan inspiratif. Beri jeda jelas di antara tiga poin (setiap poin = panel muncul).

```
[warmly] MENCINTAI Rupiah, berarti merawat dan menjaganya. [pause] [proud] BANGGA terhadap Rupiah, berarti menjadikannya sebagai simbol identitas dan kedaulatan bangsa. [pause] [confident] MEMAHAMI Rupiah, berarti mengenali ciri keasliannya... serta menggunakannya dengan tepat.
```

## Scene 5 — Perjuangan di Era Digital
**Timecode:** 01:15–01:35 · **VO mulai:** 01:16 · **Target maks:** 17 dtk
**Arah:** Ringan, modern, sedikit ceria. Kalimat terakhir lebih bijak/pelan.

```
[cheerful] Di era digital, cara kita bertransaksi terus berkembang. [short pause] [confident] Menggunakan uang tunai maupun pembayaran digital, keduanya membutuhkan kesadaran... dan tanggung jawab. [pause] [serious] [softly] Sebab, kemudahan harus selalu disertai kebijaksanaan.
```

## Scene 6 — Musuh yang Tidak Terlihat
**Timecode:** 01:35–01:55 · **VO mulai:** 01:35.5 · **Target maks:** 18 dtk
**Arah:** Menegangkan, waspada. Tiga ancaman diucapkan tegas satu per satu.

```
[tense] [softly] Namun... ada tantangan yang sering tidak kita sadari. [pause] [cautious] Perilaku konsumtif. [short pause] Penipuan digital. [short pause] Dan kelalaian dalam bertransaksi. [pause] [serious] Inilah tantangan generasi sekarang: [short pause] bukan hanya mampu MENGGUNAKAN teknologi, [determined] tetapi juga mampu MENGENDALIKANNYA.
```

## Scene 7 — Pahlawan Masa Kini
**Timecode:** 01:55–02:15 · **VO mulai:** 01:56 · **Target maks:** 18 dtk
**Arah:** Bangkit, optimistis, makin bersemangat menuju akhir.

```
[warmly] Kita bisa memulai dari hal sederhana. [short pause] [confident] Merawat Rupiah... menggunakan Rupiah dengan bangga... mengelola pengeluaran... serta memastikan setiap transaksi aman. [pause] [inspired] Karena menjadi pahlawan masa kini, dimulai dari TINDAKAN NYATA.
```

## Scene 8 — Penutup: Estafet Perjuangan
**Timecode:** 02:15–02:30 · **VO mulai:** 02:15.5 · **Target maks:** 14 dtk
**Arah:** Klimaks. Khidmat di awal, lalu tegas dan membakar semangat. Kalimat terakhir pelan dan bermakna.

```
[solemn] Para pahlawan telah mewariskan kemerdekaan. [short pause] [determined] Kini, giliran kita menjaga masa depan Indonesia. [pause] [inspired] Cintai Rupiah. Bangga terhadap Rupiah. Dan pahami setiap transaksi. [pause] [dramatic] Karena perjuangan... BELUM SELESAI. [long pause] [softly] [proud] Indonesia membutuhkan kita.
```

## Tips

- Bila tag tertentu terbaca sebagai kata (diucapkan), hapus tag itu. Biasanya terjadi pada suara yang bukan dari *Voice Library* v3.
- Generate 2–3 variasi per scene, lalu pilih yang paling sesuai emosinya.
- Bila memakai model **Multilingual v2** (bukan v3), hapus semua tag `[...]` dan ganti jeda dengan `<break time="0.8s" />`.
- Hasil VO taruh di `Video 1/audio/` dengan pola nama `vo_s<nomor scene>_<nama scene>.mp3`:

  | Scene | Nama file |
  | :-: | :--- |
  | 1 | `vo_s1_prolog.mp3` |
  | 2 | `vo_s2_pertanyaan.mp3` |
  | 3 | `vo_s3_rupiah-kedaulatan.mp3` |
  | 4 | `vo_s4_cinta-bangga-paham.mp3` |
  | 5 | `vo_s5_era-digital.mp3` |
  | 6 | `vo_s6_musuh-tak-terlihat.mp3` |
  | 7 | `vo_s7_pahlawan-masa-kini.mp3` |
  | 8 | `vo_s8_penutup.mp3` |
